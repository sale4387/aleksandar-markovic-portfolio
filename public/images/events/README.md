# Event images

Add optional event documentation to a matching folder, then list the public paths in the event's `images` array in `src/data/portfolio.ts`.

- `international-youth-day-2010/`
- `language-courses-2011/`
- `belgrade-get-together-2015/`
- `liftit-2016/`
